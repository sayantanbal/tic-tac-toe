# Tic Tac Toe

Polished two-player Tic Tac Toe built with React, TypeScript, Vite, and Tailwind CSS. The UI features a glassmorphism-inspired board, live turn feedback, animated win strike-throughs, and quick reset controls.

## Live Demo

- https://tictactoe-sb.netlify.app

## Repository

- https://github.com/sayantanbal/tic-tac-toe

## Features

- 3x3 board with two-player turn system
- Winner and draw detection
- Animated strike-through on winning line
- Reset game option
- Status card for current turn and result
- Responsive, polished UI

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS

## Run Locally

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```

## Preview Production Build

```bash
bun run preview
```
